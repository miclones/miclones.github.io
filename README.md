# CiteSurge test fixture

A small static website used to test CiteSurge. **Everything in it is invented.** Quorvane Lantern Hall is not a real
place, organisation or event, and no real person or company is described. Nothing can be bought or booked, and no
page collects any information.

The pages are hidden from search engines with `noindex`. Some pages are deliberately imperfect test cases, so please
do not treat anything here as an example to copy.

- `main` is the default published set.
- `clean` is a second set of the same pages. GitHub Pages publishes one branch at a time, from `/docs`.
