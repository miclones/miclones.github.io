The map room

The map room is the smallest space in the hall. A single round lantern hangs above a table covered with hand drawn plans showing where every shelf, bench and rack belongs.

The oldest plan is faded and folded into quarters. Newer ones are coloured by season, with blue for the winter layout and yellow for the summer one, and a pencil key explains the little symbols used for lamps, hooks and windows.

Visitors who like puzzles can try to match each drawing to the arrangement described on the cards, then note any bench that appears to have wandered.
